# GitHub Profile setup

This is the special public profile repository for `Prathmesh-2023`.

## 1. Copy files

Copy the contents into the repository named exactly:

`Prathmesh-2023`

## 2. Push

```powershell
git add .
git commit -m "feat: build AI engineering profile"
git push -u origin main
```

## 3. Run the visual updater

GitHub → Actions → **Update profile visuals** → **Run workflow**.

The workflow uses the repository's `GITHUB_TOKEN` to query public contribution data and regenerate the self-hosted contribution SVG.

## 4. Verify

Open `https://github.com/Prathmesh-2023`.
